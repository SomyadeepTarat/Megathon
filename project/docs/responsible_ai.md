# Responsible AI note — Person 5

No LLM generates numerical valuations. The fitted regression and held-out residual calibration generate the outputs. Property prices reflect location, market timing, unobserved quality and selection effects; changing EPC in a regression cannot prove a causal retrofit premium. Outputs must not promise a sale price, mortgage eligibility or financial return.

The bundled fixture contains explicitly invented prices and regions. Its performance demonstrates software behavior only. Normal inference refuses real-world uplift from it. Observed data needs documented sources/licensing and reviewed energy evidence before uplift is enabled. Missing data is unavailable, never silently zero. Unsupported regions or training ranges are rejected. Negative predicted differences remain visible.

Before using observed data, evaluate error and coverage by region, property type and EPC rating, inspect sparse strata and time drift, and consider proxy bias. No demographic fairness assessment has run. Training does not require names, exact addresses or personal financial data; public source availability does not remove licensing obligations. Store pseudonymous building/customer IDs with limited access.

Nominal conformal coverage is marginal and depends on exchangeability. It does not guarantee coverage for a particular home or a hypothetical retrofit. Contrast intervals have no empirical paired validation. Explain these limitations next to the figures.

LLM evaluation combines number-token checks with independent human review of groundedness, accuracy, completeness, tool use and missing-value handling. Matching a number alone cannot establish its meaning, units or attribution. Pending review must remain pending; never report challenge targets as achieved from empty responses or fabricated ratings.
